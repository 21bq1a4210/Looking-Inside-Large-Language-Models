Glossary

Transformer

The foundational architecture for modern LLMs, using self-attention to process text.

Tokenization

Breaking text into smaller units (tokens) for the model to process.

Self-Attention

Allows the model to weigh the importance of different tokens when processing any single token.

Feedforward Network

A neural network in each Transformer block that processes the output from self-attention.

LM Head

The final layer that predicts the next token based on all the processed information.
