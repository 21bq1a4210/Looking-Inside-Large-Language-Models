Inside a Transformer Block

Each block contains two main sub-layers that work together.

Self-Attention

Determines the "focus" for each token by scoring the relevance of all other tokens in the sequence.

+

Feed-Forward Network

A standard neural network that processes the output of the attention layer, adding complexity.

Normalization and residual connections are applied around each of these two sub-layers.
